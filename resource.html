点击「在线演示」后,顶部标签依次为:受热均匀 / 受热不均 / 案例展示 / 随堂测验,「自动演示」一键播放四步链条。

环节教师活动时间
一、情境导入提问:"晴朗的白天,海边风是从海吹向陆地,还是从陆地吹向海?"举手表决后不公布答案,播放"案例展示—白天海风"动画验证,制造认知冲突,引出课题。3分钟
二、原理讲解切换"受热不均"板块,按四步链条逐步演示,每步停下来让学生预测。强调:①温差是根本原因;②热上升、冷下沉;③高空与近地面气压相反;④等压面高压处上凸、低压处下凹。12分钟
三、合作探究同桌两人一组:一人操作动画切换"海风/陆风",另一人口述环流过程,然后互换。请两组上台展示。10分钟
四、当堂检测打开"随堂测验"板块,8题当堂完成;错题即时讲评(题目与解析见本页下方)。10分钟
五、总结提升迁移提问:海陆换成山坡与山谷呢?城市与郊区呢?回放"完整热力环流",齐读总结:"受热不均→垂直运动→气压差异→水平运动,热力环流是大气运动最基本的形式。"5分钟

板书:地面冷热不均(根本原因)→ 空气垂直运动(热上升·冷下沉)→ 同一水平面气压差异(高空与近地面相反)→ 空气水平运动(高压→低压)→ 热力环流

易错点:①顺序——先垂直、后水平;②比较气压必须在同一水平面上;③高空与近地面气压相反、等压面高压处上凸。

📝 当堂测验卷(8题)

点击每题下方「显示答案」查看答案解析;完整打印版见资源包内 Word 文档。

1. 热力环流形成的根本原因是(　)
A. 大气水平运动　B. 地面冷热不均　C. 地转偏向力　D. 气压带风带
B　解析:地面冷热不均导致空气垂直运动,进而产生气压差异和水平运动,是热力环流的根本原因。
2. 受热地区的近地面气压状况是(　)
A. 高压　B. 低压　C. 与周围相等　D. 无法判断
B　解析:受热地区空气膨胀上升,近地面空气减少,形成低压。
3. 高空与近地面的气压分布关系是(　)
A. 完全相同　B. 完全相反　C. 没有关系　D. 高空一定高于近地面
B　解析:热力环流中,某地近地面为高压则其高空为低压,反之亦然。
4. 等压面在高压处(　)
A. 向下凹陷　B. 向上凸起　C. 保持水平　D. 垂直地面
B　解析:等压面上凸处气压高于同高度周围,即高压;下凹处为低压。
5. 白天,沿海地区的风通常从(　)
A. 陆地吹向海洋　B. 海洋吹向陆地　C. 北方吹向南方　D. 高空吹向地面
B　解析:白天陆地升温快形成低压,海洋形成高压,近地面风从海洋吹向陆地,即海风。
6. 夜晚,山谷地区的风通常(　)
A. 沿山坡向上吹　B. 沿山坡向下吹　C. 从山谷吹向山顶　D. 静止无风
B　解析:夜晚山坡降温快、山谷降温慢,近地面风沿山坡向下吹,即山风。
7. 城市热岛环流中,近地面的风(　)
A. 从城市吹向郊区　B. 从郊区吹向城市　C. 沿城市边缘旋转　D. 只在白天出现
B　解析:城市气温高于郊区,城市空气上升,近地面风从郊区吹向城市。
8. 热力环流的形成顺序是(　)
A. 水平运动→垂直运动→受热不均　B. 受热不均→垂直运动→气压差异→水平运动　C. 气压差异→受热不均→垂直运动　D. 垂直运动→水平运动→受热不均
B　解析:受热不均引起垂直运动,造成同一水平面气压差异,进而产生水平运动,形成环流。
